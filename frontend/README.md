# Reactフロントエンド

React・TypeScript・Vite・TanStack Queryで、移行前の画面を再現します。Pythonの認証・API・給与計算・セッション保存形式は共通です。

- `main.tsx`：ログイン／アプリの入口。
- `SessionGate.tsx`：初回・復帰時の認証確認、定期確認、非表示制御。
- `App.tsx`：3つの画面、先読み、タブ別のスクロール位置。
- `pages.tsx`：既存のカレンダー・スタッフ検索・給与概算。
- `Details.tsx`：日別／スタッフ詳細、戻る履歴、フォーカス・スクロール復元。Radix Dialogでフォーカスとモーダルのアクセス制御を扱います。
- `data.ts`・`hooks.ts`：既存キャッシュとTanStack Queryの接続、表示中の再取得。
- `style.css`：移行前の`static/style.css`とログイン用CSSを維持。末尾だけにReact・Radixとの接続に必要な指定を追加しています。

`npm ci`で導入し、`npm run build`で型検査と配信用ファイルの作成、`npm test`で人工データによるキャッシュ・Reactの回帰テストを実行します。`npm run dev`はFlaskから配信するファイルを監視ビルドします。ブラウザではFlaskのURLを開き、変更後に再読み込みしてください。

## デザインの維持

紫色の配色、ヘッダー、PCの月見出し、スマートフォンの月切り替え、下部ナビゲーション、検索・給与画面、詳細とログイン画面は移行前の構成を維持します。Bootstrap 5.3.0・Bootstrap Icons 1.11.3・Google Fontsの読み込みも従来どおりです。新しいテーマ、見出し、アバターなどの装飾は追加しません。

## ローディング表示

`components/arc/LoadingIndicator.tsx`はArc Libraryのスケルトンとボタンスピナーを必要な範囲だけ取り込んだものです。画面内の初回取得、検索・給与入力の待機ではスケルトン、取得済みデータの更新では小さなスピナーを表示します。JavaScriptの実行前・画面分割ファイルの取得中・認証確認中は中央のスピナーだけを表示します。初期HTMLにも共通のインラインCSSを含め、サンプル説明やログイン操作が読み込み前に一瞬表示されることを防ぎます。サンプルの架空データ表記は画面の準備後に表示します。画面には待機テキストを出さず、`aria-label`で読み上げに伝えます。エラーと再試行の案内は表示します。ライセンス・取得元・変更内容は[コンポーネントの説明](components/arc/README.md)に記載しています。Motionや新しいグローバルテーマは追加しません。

## キャッシュの境界

`static/data-cache.js`の既存キャッシュを継続利用し、TanStack Queryは同じエントリーを観測します。上流の残存有効期間、月のリビジョン、最大3か月・100エントリーの制限を維持します。先読みも同じ取得経路を使います。React側の観測キャッシュも、既存キャッシュから除去されたエントリーを取得完了時に除去します。

従業員情報・シフトはメモリ内だけに保持し、HTTP応答の`no-store`を維持します。ログアウト・認証切れ・別タブでの認証変更・ページ離脱時にキャッシュを消し、通信を中止します。遅れて届いた応答は世代番号で破棄します。給与の入力設定だけは従来と同じ利用者別キーで`localStorage`へ保存します。

アクセストークン（1時間）とリフレッシュトークン（30日）はHttpOnly Cookieで扱います。`data.ts`はAPIの401で再発行を1件にまとめ、元の要求を1回だけ再試行します。再発行の一時障害では状態を保持して再試行できるようにし、再発行の拒否やログアウトでは通信を中断して遅延応答を破棄します。サンプル表示では再発行を行いません。
